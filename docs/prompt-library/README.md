# Prompt Library — คลัง System Prompt ฝั่งผู้สร้าง

สถานะ: ร่างสำหรับวางแผน วันที่ 28 กันยายน 2026 ยังไม่เชื่อมหน้าแอป

คลังกลางสำหรับแท็บ **Prompt Library** ใน Single-char และ Multi-char ผู้สร้างเลือกกฎและระบบตามสถานการณ์ แล้วตรวจข้อความก่อนเพิ่มลงโปรเจกต์ คำสั่งในคลังเขียนเป็น System Prompt สำหรับการตั้งค่าตัวละคร ส่วน OOC เป็นแนวทางสั่งระหว่างเล่นและอยู่นอกขอบเขตชุดแรก

## ไฟล์

- `library.json`: ข้อมูลต้นฉบับสำหรับนำไปใช้พัฒนาหน้าแอป
- `LIBRARY.md`: ฉบับอ่านและคัดลอก สร้างจาก JSON ให้เนื้อหาตรงกัน
- `IMPLEMENTATION_PLAN.md`: แผนพัฒนา จุดเชื่อมกับโค้ด และเกณฑ์ตรวจรับ

## ข้อตกลงข้อมูล

`schemaVersion` คือรุ่นรูปแบบไฟล์ ไม่ใช่รุ่นโปรเจกต์ตัวละคร `id` ของรายการต้องคงที่และไม่ซ้ำ `category` ต้องอยู่ในหมวดที่ประกาศ `modes` ระบุบริบทที่ใช้ได้ ไม่ใช่การรับรองผลบนแพลตฟอร์มภายนอก

แต่ละรายการมี `title`, `tags`, `useWhen`, `body`, `variables`, `requires`, `conflictsWith` โดยสองฟิลด์ท้ายอ้างถึง ID ของรายการอื่น ขณะนี้ยังไม่มีคู่ขัดแย้งที่ประกาศไว้ ไม่ได้หมายความว่าคำสั่งจะไม่ขัดกับกฎเดิมของผู้สร้าง

`{{user}}` เป็น placeholder สำหรับผู้เล่นและต้องคงไว้เมื่อส่งออก ชุดแรกไม่มีตัวแปรที่ผู้สร้างต้องกรอก จึงใช้ `variables: []` หากเพิ่มภายหลังให้ใช้รูปแบบ `{ "key": "...", "label": "...", "required": true, "defaultValue": "..." }` และกำหนดการแทนค่าให้แยกจาก placeholder ของแพลตฟอร์ม

`presets` เป็นชุดเลือกเริ่มต้น ผู้สร้างยังแก้การเลือกได้ ต้องมีรายการที่ `requires` ต้องการครบและใช้ได้ใน `mode` ของชุดนั้น การคัดลอกให้ใช้เฉพาะชื่อและเนื้อหา ไม่รวม metadata

แก้เนื้อหาที่ JSON ก่อน แล้วสร้าง/ปรับ MD ให้ตรงกัน ไม่แก้สองฉบับแยกอย่างอิสระ ไฟล์นี้เป็นสเปกข้อมูลรุ่นแรก ยังไม่มี runtime validator หรือ import ในแอป

## การตีความและแหล่งอ้างอิง

ตีความ “ระบบโบ้” ว่าเป็นพัฒนาการสำนึกผิด ง้อ และรับผิดชอบต่อความสัมพันธ์ โดยผู้เล่นเป็นผู้ตัดสินใจว่าจะให้อภัยหรือไม่ สามารถปรับความหมายหรือเพิ่มโทนดราม่าในชุดถัดไปได้

- [คู่มือ AI Roleplay MultiCharacter ของ IIKHAEDAz](https://iikhaedaz.github.io/ai-roleplaymulti/#template-L): ใช้แนวคิดการจัดคู่มือและแม่แบบสำหรับผู้สร้าง อ่านหน้าโดยรวมได้ แต่ยังไม่ได้ตรวจเนื้อหาแม่แบบ L ที่โหลดแบบไดนามิกโดยเฉพาะ
- [Prompt Library OOC & MMR ของ IIKHAEDAz](https://iikhaedaz.github.io/prompt-library/): ใช้เป็นแนวทางการแบ่งหมวดและเลือกคัดลอกคำสั่งตามปัญหา

ตรวจแหล่งอ้างอิงวันที่ 28 กันยายน 2026 ข้อความในคลังนี้เขียนใหม่สำหรับ SedChar ไม่ใช่การนำชุดแม่แบบของเว็บต้นทางมารวมทั้งชุด และยังไม่ได้ทดสอบผลลัพธ์กับโมเดลของแพลตฟอร์มปลายทาง
